# Συντήρηση της τεκμηρίωσης {#maintaining-the-documentation}

Για όποιον κυκλοφορεί νέα έκδοση. Κάντε τα βήματα με αυτή τη σειρά.

1. **Ξαναδημιουργήστε τις σελίδες αναφοράς** από τον κώδικα:

   ```bash
   python tools/gen_docs_reference.py
   python tools/gen_docs_reference.py --check   # πρέπει να τελειώσει με 0
   ```

   Αυτό ξαναγράφει τις [Αναφορά εντολών](../cli-reference.md) και τη
   [Λίστα στηλών](../columns.md). Ποτέ μην τις επεξεργάζεστε με το χέρι.
2. **Κατάλογος των αλλαγών από την τελευταία κυκλοφορία:**

   ```bash
   git log --oneline v<VERSION>..HEAD
   ```

   Το `<VERSION>` είναι η τελευταία κυκλοφορημένη έκδοση (χωρίς ετικέτα ακόμα: όλο το
   `git log --oneline`). Κάθε νέα λειτουργία, επιλογή ή στήλη θέλει τη σελίδα της και μια
   γραμμή στην ενότητα **Docs** του
   [CHANGELOG.md](https://github.com/Holdi601/3DHeat-Ext-WoWs/blob/main/CHANGELOG.md).
3. **Ανεξάρτητος έλεγχος.** Κάποιος που δεν έγραψε τις σελίδες (ένας άνθρωπος ή ένας
   πράκτορας) διαβάζει το README, κάθε σελίδα και κάθε εικόνα ως τρεις αναγνώστες: έναν
   αρχάριο που δεν έχει χρησιμοποιήσει ποτέ τερματικό, ένα παιδί 8 ετών, και έναν
   επαγγελματία που ελέγχει κάθε επιλογή, στήλη και μονάδα απέναντι στον κώδικα. Ελέγχουν
   επίσης τα διαγράμματα απέναντι στον κώδικα, και ότι καμία σελίδα δεν ονομάζει έναν
   πραγματικό χάρτη, επίπεδο, παίκτη ή αγώνα, ούτε δίνει αριθμούς από πραγματικά replays.
4. **Διορθώστε όσα βρήκε ο έλεγχος.** Έπειτα τρέξτε ξανά το βήμα 1 και ξαναζωγράφισε τις
   εικόνες των οποίων αλλάξτε η έξοδος.
5. **Μεταφράσεις.** Κάθε σελίδα κάτω από το `docs/<γλώσσα>/` καταγράφει το hash της
   αγγλικής σελίδας από την οποία μεταφράστηκε. Μεταφράστε ξανά κάθε σελίδα της οποίας
   αλλάξτε η αγγλική πηγή, και τις ετικέτες των διαγραμμάτων μαζί της. Έπειτα ελέγξτε κάθε
   γλώσσα: καθαρή για και τους τρεις αναγνώστες, σωστές ετικέτες, και τις ίδιες λέξεις με
   αυτές που χρησιμοποιεί ο προβολέας 3DHeat σε εκείνη τη γλώσσα.
6. **Κυκλοφορία:** ανεβάστε το `VERSION` και βάλτε την ετικέτα `v<VERSION>`. **Ώθηση
   (push) μόνο με την άδεια του ιδιοκτήτη.**

## Μεταφράσεις: οι εντολές {#translations-the-commands}

Ο ιστότοπος μεταφράζεται στις 40 γλώσσες του προβολέα 3DHeat: τα αγγλικά στο `docs/`, κάθε
άλλη γλώσσα στο `docs/<lang>/` με τα ίδια ονόματα αρχείων. Το `tools/docs_i18n.py` κάνει
τη διαχείριση:

```bash
python tools/docs_i18n.py hashes             # μετά από κάθε αλλαγή στα αγγλικά: κατέγραψε το hash κάθε σελίδας
python tools/docs_i18n.py svg-strings        # μετά από κάθε αλλαγή εικόνας: οι ετικέτες για μετάφραση
python tools/docs_i18n.py status             # ανά γλώσσα: τρέχουσες, ξεπερασμένες, λείπουσες σελίδες
python tools/docs_i18n.py todo --lang de     # οι γερμανικές σελίδες για (ξανα)μετάφραση
python tools/docs_i18n.py svg-build --lang de    # γερμανικές εικόνες από το docs/assets/i18n/svg/de.json
python tools/docs_i18n.py finish --lang de   # σφραγίστε τις γερμανικές σελίδες με το αγγλικό τους hash
python tools/docs_i18n.py check              # έξοδος 1 όταν τα hash ή οι ετικέτες είναι ξεπερασμένα
```

Μεταφράστε μόνο όσα απαριθμεί το `todo`: κρατήστε το Markdown, τους συνδέσμους, τον κώδικα και
τα ονόματα αρχείων και στηλών ως έχουν, μεταφράστε τους τίτλους και τις περιγραφές των
εικόνων, και χρησιμοποιήστε τις δικές του λέξεις του προβολέα 3DHeat για τα κουμπιά και τα
πάνελ του (`src/i18n/locales/<lang>/`). Οι παραγόμενες σελίδες αναφοράς και οι εικόνες
τερματικού μένουν στα αγγλικά. Στον ιστότοπο, μια ξεπερασμένη μετάφραση το λέει και
συνδέει την αγγλική σελίδα· μια λείπουσα πέφτει πίσω στα αγγλικά. Το μενού γλωσσών της
κεφαλίδας και η ανακατεύθυνση της αρχικής σελίδας βάσει γλώσσας του περιηγητή προέρχονται
από το `docs/_includes/`.
