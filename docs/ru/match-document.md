# Документ матча {#the-match-document}

`<match>.match.json` содержит всё, что говорит реплей и что не является строкой таблицы. Вкладка
«Матч» просмотрщика читает именно этот файл. (В коде он называется summary, сводка.)

![Начало синтетического документа матча и его ключи](../assets/img/match-document.svg)

## Бой {#the-battle}

| Ключ | Что |
|---|---|
| `format`, `version` | `heat3d-wows-match`, `2` |
| `game`, `match`, `map`, `mapName` | `World of Warships`; id боя; карта так, как её называет игра (`spaces/<map>`), и её отображаемое название |
| `clientVersion`, `streamVersion` | версия игры из заголовка и та, которую говорит поток пакетов |
| `recorded` | когда был записан реплей, как его записывает игра |
| `player`, `vehicle` | игрок, который записал реплей, и его корабль |
| `gameType`, `scenario` | тип боя (`RandomBattle`, ...) и сценарий, из заголовка |
| `duration` | лимит времени боя в секундах, из заголовка |
| `truncated` | запись остановилась раньше |
| `battleStart`, `recordingSeconds` | начало боя (первый момент, когда вообще движется какой-либо корабль) и длительность записи, в секундах |
| `positionPacket`, `ownPositionPacket` | номера пакетов, в которых пришли положения: других кораблей и игрока, который записал реплей |
| `deathMethod` | номер метода, в котором найдены потопления |
| `hz`, `ownHz`, `positions` | выборок в секунду для других кораблей и для собственного; строки положений |
| `units` | единицы мира (15 м по корпусам, 30 м по дальностям игры); x — восток, y — вверх, z — север |
| `events` | количество строк таблицы каждого события |
| `decoded` | номера методов и пакетов, найденные для каждого вида сообщений |

## Игроки и события {#players-and-events}

| Ключ | Что |
|---|---|
| `players` | одна запись на корабль: имя, `ally` или `enemy`, номер и название корабля, сущность, выборки, убийства, выжил ли; `seen` (нанесённый и полученный урон, снаряды, торпеды и последнее здоровье, которые видел клиент); `header` (запись из состава) и `record` (запись игрока из потока, по номеру ключа) |
| `kills` | каждое потопление: время, жертва, убийца, номер причины, место |
| `chat` | каждая строка чата, с каналом и отправителем |
| `damageStats` | собственная статистика игрока, который записал реплей, в том виде, как её ведёт игра: по оружию и виду, счётчик и величина (вид 0 — нанесённый урон) |
| `avatarPickles` | каждый вызов в pickle игроку, который записал реплей, прочитанный, по номеру метода |

## Заголовок, результаты и проверки {#header-results-and-checks}

| Ключ | Что |
|---|---|
| `header` | первый блок JSON целиком, кроме состава: режим игры, погода, границы карты, размеры команд и другое |
| `moreBlocks` | блоки JSON после первого, как они есть |
| `blockIds` | 15.x: аккаунт игрока, который записал реплей, и id боя, прочитанные как текст |
| `results` | 15.x: результаты, которые эти клиенты хранят в потоке |
| `entities` | каждая сущность, которую создаёт поток: её номер типа и роль, когда она появилась в поле зрения клиента и когда ушла |
| `selfCheck` | подсчёт полноты ([Полнота](completeness.md)) и проверки сущностей, результатов, идентификаторов и версии |
