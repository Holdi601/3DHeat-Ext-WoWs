# Одржавање документације {#maintaining-the-documentation}

За онога ко објављује нову верзију. Радите кораке овим редом.

1. **Поново генеришите референтне странице** из кода:

   ```bash
   python tools/gen_docs_reference.py
   python tools/gen_docs_reference.py --check   # мора да заврши са 0
   ```

   Ово пише изнова [Референцу команди](../cli-reference.md) и
   [Списак колона](../columns.md). Никад их не уређујте руком.
2. **Наведите шта се променило од последњег издања:**

   ```bash
   git log --oneline v<VERSION>..HEAD
   ```

   `<VERSION>` је последња објављена верзија (још нема ознаке: цео
   `git log --oneline`). Свака нова функција, опција или колона треба своју
   страницу и ред у одељку **Docs** у
   [CHANGELOG.md](https://github.com/Holdi601/3DHeat-Ext-WoWs/blob/main/CHANGELOG.md).
3. **Независан преглед.** Неко ко није писао странице (особа или агент) чита
   README, сваку страницу и сваку слику као три читаоца: почетник који никад
   није користио терминал, осмогодишњак, и стручњак који проверава сваку опцију,
   колону и јединицу према коду. Они такође проверавају дијаграме према коду, и
   да ниједна страница не наводи стварну мапу, ниво, играча или меч, нити даје
   бројке из правих реплеја.
4. **Поправите што је преглед нашао.** Затим поново покрените корак 1 и
   нацртајте наново слике чији се излаз променио.
5. **Преводи.** Свака страница под `docs/<language>/` бележи хеш енглеске
   странице из које је превођена. Поново преведите сваку страницу чији се
   енглески извор променио, укључујући ознаке на дијаграмима. Затим прегледајте
   сваки језик: јасан за сва три читаоца, ознаке тачне, и исте речи које 3DHeat
   приказач користите на том језику.
6. **Издање:** подигните `VERSION` и обележите `v<VERSION>`. **Гурајте тек
   након сагласности власника.**

## Преводи: команде {#translations-the-commands}

Сајт је преведен на 40 језика 3DHeat приказача: енглески је у `docs/`, сваки
други језик у `docs/<lang>/` с истим именима датотека. `tools/docs_i18n.py` води
евиденцију:

```bash
python tools/docs_i18n.py hashes             # после сваке енглеске измене: забележи хеш сваке странице
python tools/docs_i18n.py svg-strings        # после сваке измене слике: ознаке за превод
python tools/docs_i18n.py status             # по језику: тренутне, застареле, недостајуће странице
python tools/docs_i18n.py todo --lang de     # немачке странице за (поновни) превод
python tools/docs_i18n.py svg-build --lang de    # немачке слике из docs/assets/i18n/svg/de.json
python tools/docs_i18n.py finish --lang de   # означи немачке странице енглеским хешем
python tools/docs_i18n.py check              # излаз 1 кад су хешеви или ознаке застарели
```

Преводите само оно што `todo` наводи: Markdown, везе, код, имена датотека и
колона оставите како јесу, преведите наслове и описе слика, и користите речи
3DHeat приказача за његова дугмад и панеле (његов `src/i18n/locales/<lang>/`).
Генерисане референтне странице и терминалне слике остају на енглеском. На сајту
застарео превод то каже и води на енглеску страницу; недостајући пада на
енглески. Језички мени у заглављу и преусмеравање на почетној страници према
језику прегледача долазе из `docs/_includes/`.
