# Документ меча {#the-match-document}

`<match>.match.json` држи све што реплеј каже, а што није ред табеле. Картица
приказача Меч чита њега. (Код га зове резиме.)

![Почетак синтетичког документа меча, и његови кључеви](../assets/img/match-document.svg)

## Битка {#the-battle}

| Кључ | Шта је |
|---|---|
| `format`, `version` | `heat3d-wows-match`, `2` |
| `game`, `match`, `map`, `mapName` | `World of Warships`; ид битке; мапа како је игра назива (`spaces/<map>`) и њено приказно име |
| `clientVersion`, `streamVersion` | верзија игре из заглавља, и како је каже низ пакета |
| `recorded` | када је реплеј снимљен, како га игра записује |
| `player`, `vehicle` | снимајући играч и његов брод |
| `gameType`, `scenario` | врста битке (`RandomBattle`, ...) и сценарио, из заглавља |
| `duration` | ограничење трајања битке у секундама, из заглавља |
| `truncated` | снимање је стало рано |
| `battleStart`, `recordingSeconds` | почетак битке (први тренутак кад се било који брод помери) и дужина снимања, у секундама |
| `positionPacket`, `ownPositionPacket` | бројеви пакета у којима су стигле позиције: туђих бродова, снимајућег играча |
| `deathMethod` | број метода у којем су потапања нађена |
| `hz`, `ownHz`, `positions` | узорци у секунди туђих бродова и свог брода; редови позиција |
| `units` | јединице света (15 m по трупу, 30 m по игриним дометима); x исток, y горе, z север |
| `events` | број редова табеле за сваки догађај |
| `decoded` | бројеви метода и пакета нађени за сваку врсту поруке |

## Играчи и догађаји {#players-and-events}

| Кључ | Шта је |
|---|---|
| `players` | један унос по броду: име, `ally` или `enemy`, број и име брода, ентитет, узорци, убиства, преживео; `seen` (нанета и примљена штета, зрна, торпеда и последње здравље које је клијент видео); `header` (унос из списка) и `record` (запис играча из низа, по броју кључа) |
| `kills` | свако потапање: време, жртва, убица, број узрока, место |
| `chat` | сваки ред ћаскања, с каналом и пошиљаоцем |
| `damageStats` | сопствена статистика снимајућег играча онако како је игра води: по оружју и врсти, број и износ (врста 0 је нанета штета) |
| `avatarPickles` | сваки pickle-ован позив упућен снимајућем играчу, декодиран, по броју метода |

## Заглавље, резултати и провере {#header-results-and-checks}

| Кључ | Шта је |
|---|---|
| `header` | први JSON блок, цео осим списка: режим игре, време, граница мапе, величине тимова и још |
| `moreBlocks` | JSON блокови после првог, онакви какви јесу |
| `blockIds` | 15.x: налог снимајућег играча и ид битке, прочитани као текст |
| `results` | 15.x: резултати, које ови клијенти чувају у низу |
| `entities` | сваки ентитет који низ ствара: његов број типа и улога, када је ушао у поглед клијента и када га је напустио |
| `selfCheck` | бројање потпуности ([Потпуност](completeness.md)) и провере ентитета, резултата, идова и верзије |
