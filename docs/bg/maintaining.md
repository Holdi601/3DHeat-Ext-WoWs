# Поддръжка на документацията {#maintaining-the-documentation}

За този, който пуска нова версия. Изпълнявайте стъпките в този ред.

1. **Регенерирайте справочните страници** от кода:

   ```bash
   python tools/gen_docs_reference.py
   python tools/gen_docs_reference.py --check   # трябва да завърши с код 0
   ```

   Това пренаписва [Справка за командите](../cli-reference.md) и
   [Списък на колоните](../columns.md). Никога не редактирайте тези две ръчно.
2. **Изброете какво се е променило от последното издание:**

   ```bash
   git log --oneline v<VERSION>..HEAD
   ```

   `<VERSION>` е последната издадена версия (без таг още: целият `git log --oneline`). Всяка нова
   функция, опция или колона се нуждае от своята страница и от ред в раздела **Docs** на
   [CHANGELOG.md](https://github.com/Holdi601/3DHeat-Ext-WoWs/blob/main/CHANGELOG.md).
3. **Независим преглед.** Някой, който не е писал страниците (човек или агент), чете README, всяка страница и
   всяка картинка от три гледни точки: начинаещ, който никога не е ползвал терминал, 8-годишно дете и
   професионалист, който проверява всяка опция, колона и мерна единица спрямо кода. Проверяват и
   диаграмите спрямо кода, и че никоя страница не назовава истинска карта, ниво, играч или мач, нито дава
   цифри от истински повторения.
4. **Поправете какво е открил прегледът.** После пуснете стъпка 1 отново и прерисувайте
   картинките, чийто изход се е променил.
5. **Преводи.** Всяка страница под `docs/<language>/` записва хеша на английската страница, от която е
   преведена. Превеждайте отново всяка страница, чийто английски източник се е променил, включително етикетите
   на диаграмите. После прегледайте всеки език: ясен за и трите читатели, етикетите правилни и същите
   думи, каквито ползва визуализаторът на 3DHeat на този език.
6. **Издаване:** повишете `VERSION` и сложете таг `v<VERSION>`. **Изпращайте (push) само след
   разрешение от собственика.**

## Преводи: командите {#translations-the-commands}

Сайтът е преведен на 40-те езика на визуализатора на 3DHeat: английският е в `docs/`, всеки друг
език – в `docs/<lang>/` със същите имена на файлове. `tools/docs_i18n.py` поддържа записите:

```bash
python tools/docs_i18n.py hashes             # след всяка английска промяна: записва хеша на всяка страница
python tools/docs_i18n.py svg-strings        # след всяка промяна на картинка: етикетите за превод
python tools/docs_i18n.py status             # по език: актуални, остарели, липсващи страници
python tools/docs_i18n.py todo --lang de     # немските страници за (ре)превод
python tools/docs_i18n.py svg-build --lang de    # немските картинки от docs/assets/i18n/svg/de.json
python tools/docs_i18n.py finish --lang de   # маркира немските страници с техния английски хеш
python tools/docs_i18n.py check              # код 1, когато хешовете или етикетите са стари
```

Превеждайте само това, което `todo` изброява: запазвайте Markdown, връзките, кода, имената на файлове и колони
такива, каквито са, превеждайте заглавията и описанията на картинките, и ползвайте собствените думи на визуализатора
на 3DHeat за бутоните и панелите му (неговите `src/i18n/locales/<lang>/`). Генерираните справочни страници и
терминалните картинки остават на английски. На сайта остарелият превод го казва и сочи английската страница; липсващият
пада към английския. Менюто за езици в заглавната част и пренасочването по езика на браузъра на началната страница идват от `docs/_includes/`.
