# Документ матчу {#the-match-document}

`<match>.match.json` містить усе, що повтор розповідає і що не є рядком таблиці.
Вкладка «Матч» переглядача читає саме його. (У коді його називають підсумком.)

![Початок синтетичного документа матчу і його ключі](../assets/img/match-document.svg)

## Бій {#the-battle}

| Ключ | Що це |
|---|---|
| `format`, `version` | `heat3d-wows-match`, `2` |
| `game`, `match`, `map`, `mapName` | `World of Warships`; ідентифікатор бою; карта, як її називає гра (`spaces/<map>`), і її назва для показу |
| `clientVersion`, `streamVersion` | версія гри із заголовка і та, що каже потік пакетів |
| `recorded` | коли записано повтор, як це записує гра |
| `player`, `vehicle` | гравець, що записав повтор, і його корабель |
| `gameType`, `scenario` | тип бою (`RandomBattle`, ...) і сценарій, із заголовка |
| `duration` | ліміт часу бою в секундах, із заголовка |
| `truncated` | запис зупинився раніше |
| `battleStart`, `recordingSeconds` | початок бою (перший момент, коли рухається будь-який корабель) і тривалість запису, у секундах |
| `positionPacket`, `ownPositionPacket` | номери пакетів, у яких прийшли положення: інших кораблів, власного корабля гравця |
| `deathMethod` | номер методу, у якому знайдено потоплення |
| `hz`, `ownHz`, `positions` | відліків на секунду для інших кораблів і для власного; рядки положень |
| `units` | світові одиниці (15 м за корпусами, 30 м за дальностями гри); x — схід, y — вгору, z — північ |
| `events` | кількість рядків таблиці кожної події |
| `decoded` | номери методів і пакетів, знайдені для кожного виду повідомлень |

## Гравці і події {#players-and-events}

| Ключ | Що це |
|---|---|
| `players` | один запис на корабель: назва, `ally` або `enemy`, номер і назва корабля, сутність, відліки, вбивства, чи вижив; `seen` (завдана і отримана шкода, снаряди, торпеди і останнє здоров'я, які бачив клієнт); `header` (запис зі складу) і `record` (запис гравця з потоку, за номером ключа) |
| `kills` | кожне потоплення: час, жертва, вбивця, номер причини, місце |
| `chat` | кожен рядок чату з каналом і відправником |
| `damageStats` | власна статистика гравця, що записав повтор, як її веде гра: за зброєю і видом — лічильник і сума (вид 0 — завдана шкода) |
| `avatarPickles` | кожен пікловий виклик гравцеві, що записав повтор, декодований, за номером методу |

## Заголовок, результати і перевірки {#header-results-and-checks}

| Ключ | Що це |
|---|---|
| `header` | перший блок JSON, увесь, крім складу: режим гри, погода, межа карти, розміри команд і більше |
| `moreBlocks` | блоки JSON після першого, як вони є |
| `blockIds` | 15.x: обліковий запис гравця, що записав повтор, і ідентифікатор бою, прочитані як текст |
| `results` | 15.x: результати, які ці клієнти зберігають у потоці |
| `entities` | кожна сутність, яку створює потік: її номер типу і роль, коли вона з'явилася в полі зору клієнта і коли зникла |
| `selfCheck` | лічильник повноти ([Повнота](completeness.md)) і перевірки сутностей, результатів, ідентифікаторів і версії |
