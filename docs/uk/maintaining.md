# Супровід документації {#maintaining-the-documentation}

Для того, хто випускає нову версію. Виконуйте кроки в цьому порядку.

1. **Перегенеруйте довідкові сторінки** з коду:

   ```bash
   python tools/gen_docs_reference.py
   python tools/gen_docs_reference.py --check   # має завершитися з кодом 0
   ```

   Це переписує [Довідку з командами](../cli-reference.md) і
   [Список колонок](../columns.md). Ці дві сторінки ніколи не редагують вручну.
2. **Перегляньте, що змінилося від останнього релізу:**

   ```bash
   git log --oneline v<VERSION>..HEAD
   ```

   `<VERSION>` — остання випущена версія (якщо тегу ще немає: весь `git log --oneline`).
   Кожна нова функція, опція чи колонка потребує своєї сторінки і рядка в розділі
   **Docs** у [CHANGELOG.md](https://github.com/Holdi601/3DHeat-Ext-WoWs/blob/main/CHANGELOG.md).
3. **Незалежний перегляд.** Хтось, хто не писав сторінки (людина або агент),
   читає README, кожну сторінку і кожен малюнок як три читачі: новачок, який ніколи
   не користувався терміналом, восьмирічна дитина і професіонал, який перевіряє
   кожну опцію, колонку і одиницю виміру за кодом. Вони також перевіряють діаграми
   за кодом і те, що жодна сторінка не називає справжньої карти, рівня, гравця чи
   матчу і не наводить цифр зі справжніх повторів.
4. **Виправте те, що знайшов перегляд.** Потім знову виконайте крок 1 і перемалюйте
   ті малюнки, вихід яких змінився.
5. **Переклади.** Кожна сторінка в `docs/<language>/` записує хеш англійської
   сторінки, з якої її перекладено. Наново перекладіть кожну сторінку, чиє англійське
   джерело змінилося, з мітками на діаграмах. Потім перегляньте кожну мову: зрозуміло
   для всіх трьох читачів, мітки правильні, і ті самі слова, що їх використовує
   переглядач 3DHeat цією мовою.
6. **Реліз:** підніміть `VERSION` і поставте тег `v<VERSION>`. **Публікуйте лише
   після дозволу власника.**

## Переклади: команди {#translations-the-commands}

Сайт перекладено на 40 мов переглядача 3DHeat: англійська — у `docs/`, кожна інша
мова — у `docs/<lang>/` з тими самими назвами файлів. `tools/docs_i18n.py` веде облік:

```bash
python tools/docs_i18n.py hashes             # після будь-якої зміни англійської: записати хеш кожної сторінки
python tools/docs_i18n.py svg-strings        # після будь-якої зміни малюнка: підписи для перекладу
python tools/docs_i18n.py status             # для кожної мови: актуальні, застарілі, відсутні сторінки
python tools/docs_i18n.py todo --lang de     # німецькі сторінки для (повторного) перекладу
python tools/docs_i18n.py svg-build --lang de    # німецькі малюнки з docs/assets/i18n/svg/de.json
python tools/docs_i18n.py finish --lang de   # позначити німецькі сторінки хешем англійської
python tools/docs_i18n.py check              # код 1, коли хеші або підписи застаріли
```

Перекладайте лише те, що показує `todo`: зберігайте Markdown, посилання, код, назви
файлів і колонок як є; перекладайте заголовки й описи малюнків і використовуйте
власні слова переглядача 3DHeat для його кнопок і панелей (його
`src/i18n/locales/<lang>/`). Згенеровані довідкові сторінки і малюнки терміналу
лишаються англійськими. На сайті застарілий переклад це повідомляє і посилається на
англійську сторінку; відсутній переклад відкривається англійською. Меню мов у
шапці і перенаправлення на домашній сторінці за мовою браузера беруться з
`docs/_includes/`.
