# Перетворення повторів {#converting-replays}

## Крок за кроком {#step-by-step}

1. **Увімкніть запис у грі:** `isReplayEnabled` у `preferences.xml` гри або
   налаштування гри, якщо воно там є. Відтоді гра зберігає кожен бій у папці
   `replays` вашого встановлення World of Warships, наприклад
   `C:\Games\World_of_Warships_EU\replays`.
2. **Відкрийте термінал** у папці, куди можна записувати результати
   ([Перш ніж почати](before-you-start.md)).
3. **Запустіть конвертер** на файлах повторів або на папках, які їх містять:

   ```bash
   heat3d-wows-replay "C:\Games\World_of_Warships_EU\replays" -o out
   heat3d-wows-replay a.wowsreplay b.wowsreplay -o out
   ```

   `out` створюється в папці, де відкрито ваш термінал.
4. **Прочитайте, що пише програма.** Ви маєте побачити по одному рядку на повтор, що
   закінчується таблицею, яку він записав.
5. **Відкрийте результат** у переглядачі 3DHeat: `out/<map>/<match>.parquet` — на
   вкладці Теплова карта, `<match>.match.json` — на вкладці Матч. Або прочитайте їх
   будь-якою програмою для Parquet або JSON.

![Запуск на синтетичному повторі: перетворення, повторний запуск, пошкоджений файл, порожня папка](../assets/img/convert.svg)

На малюнку показано запуск на повторі, який тести будують у коді (справжнього повтору немає):

- повтор перетворено: `<file>: <n> positions of <n> ships at <rate> Hz (own <rate> Hz), <n> sunk, <map> (<client version>) -> <table>`;
- запущено знову, уже записаний матч пропущено: `<file>: already written, <table>`;
- файл, який не є повтором: `<file>: not converted: <why>` (у виводі помилок;
  статус виходу 1, решта повторів усе одно перетворюються);
- повтор не знайдено: `no .wowsreplay files in <folders>` (статус виходу 2).

## Опції {#options}

| Опція | За замовчуванням | Що робить |
|---|---|---|
| `replays` (один або більше) | - | файли `.wowsreplay` або папки, у яких їх шукати (з підпапками) |
| `-o`, `--out` | обов'язково | папка, куди писати: усередині папка на кожну карту |
| `--force` | вимкнено | перетворити ще раз те, що вже записано |
| `--ship-names JSON` | - | JSON-файл `{"<shipId>": "<name>", ...}`: повтори називають лише корабель гравця, що записав повтор, а інші — за номером |
| `--version` | - | вивести `heat3d-wows-replay <version>` і зупинитися |
| `-h`, `--help` | - | вивести опції і зупинитися |

Опції, як їх виводить програма: [Довідка з командами](../cli-reference.md).

## Що записується {#what-is-written}

Лише окремі файли: цей конвертер не записує файл `.3dheat` (переглядач може
упакувати їх в один: [Один файл на матч](https://holdi601.github.io/3DHeat/container.html)).
На кожен повтор у `out/<map>/` (назва карти без її `spaces/`):

| Файл | Що в ньому |
|---|---|
| `<match>.parquet` | таблиця: позиція кожного корабля в часі і кожна подія, де він був ([Таблиця](table.md)) |
| `<match>.match.json` | документ матчу: карта, версія клієнта, гравці, потоплення, чат і все інше ([Документ матчу](match-document.md)) |
| `<match>.messages.parquet` | супутній файл: кожен елемент повтору, який два файли вище не містять цілком ([Повнота](completeness.md)) |

`<match>` — це власний ідентифікатор бою, або назва файлу, якщо запис зупинився до
результатів.

## Статус виходу {#exit-status}

`0`, коли кожен повтор перетворено або пропущено; `1`, коли якийсь не вдався (решта
все одно перетворюються); `2`, коли файлів повторів не знайдено.
