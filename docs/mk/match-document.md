# Документот за мечот {#the-match-document}

`<match>.match.json` содржи сè што го кажува снимката, а не е ред од табелата. Табот Меч на прегледувачот го чита. (Кодот го вика summary.)

![Почетокот на синтетички документ за меч и неговите клучеви](../assets/img/match-document.svg)

## Битката {#the-battle}

| Клуч | Што |
|---|---|
| `format`, `version` | `heat3d-wows-match`, `2` |
| `game`, `match`, `map`, `mapName` | `World of Warships`; идот на битката; мапата како што ја именува играта (`spaces/<map>`) и нејзиното име за приказ |
| `clientVersion`, `streamVersion` | верзијата на играта од заглавието, и како ја кажува текот на пакети |
| `recorded` | кога е снимена снимката, како што го пишува играта |
| `player`, `vehicle` | снимачкиот играч и неговиот брод |
| `gameType`, `scenario` | типот на битката (`RandomBattle`, ...) и сценариото, од заглавието |
| `duration` | временското ограничување на битката во секунди, од заглавието |
| `truncated` | снимањето запрело предвреме |
| `battleStart`, `recordingSeconds` | почетокот на битката (првиот момент кога се движи кој и да е брод) и должината на снимањето, во секунди |
| `positionPacket`, `ownPositionPacket` | броевите на пакетите во кои дошле позициите: на другите бродови, на снимачкиот играч |
| `deathMethod` | бројот на методот во кој биле најдени потопувањата |
| `hz`, `ownHz`, `positions` | примероци во секунда на другите бродови и на сопствениот брод; редови на позиции |
| `units` | светски единици (15 m според трупот, 30 m според домет на играта); x исток, y горе, z север |
| `events` | бројот на редови на табелата од секој настан |
| `decoded` | методот и броевите на пакети најдени за секој вид порака |

## Играчи и настани {#players-and-events}

| Клуч | Што |
|---|---|
| `players` | една ставка по брод: име, `ally` или `enemy`, број и име на бродот, ентитет, примероци, убиства, преживеал; `seen` (нанесена и примена штета, проектили, торпеда и последно здравје што го видел клиентот); `header` (ставката од списокот) и `record` (записот на играчот од текот, по број на клуч) |
| `kills` | секое потопување: време, жртва, убиец, број на причина, место |
| `chat` | секоја линија од разговор, со канал и испраќач |
| `damageStats` | сопствената статистика на снимачкиот играч како што ја води играта: по оружје и вид, број и износ (вид 0 е нанесена штета) |
| `avatarPickles` | секој pickle-иран повик до снимачкиот играч, декодиран, по број на метод |

## Заглавие, резултати и проверки {#header-results-and-checks}

| Клуч | Што |
|---|---|
| `header` | првиот JSON блок, целиот освен списокот: режим на играта, време, граница на мапата, големини на тимови и повеќе |
| `moreBlocks` | JSON блоковите по првиот, како што се |
| `blockIds` | 15.x: профилот на снимачкиот играч и идот на битката, читани како текст |
| `results` | 15.x: резултатите, кои овие клиенти ги чуваат во текот |
| `entities` | секој ентитет што го создава текот: неговиот број на тип и улога, кога влегол во погледот на клиентот и кога излегол |
| `selfCheck` | бројката за комплетност ([Комплетност](completeness.md)) и проверките на ентитетите, резултатите, идовите и верзијата |
