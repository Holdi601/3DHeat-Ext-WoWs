# Дакумент матча {#the-match-document}

`<match>.match.json` трымае ўсё, што кажа запіс і што не з'яўляецца радком
табліцы. Яго чытае ўкладка «Матч» праглядальніка. (У кодзе ён называецца summary.)

![Пачатак сінтэтычнага дакумента матча і яго ключы](../assets/img/match-document.svg)

## Бой {#the-battle}

| Ключ | Што |
|---|---|
| `format`, `version` | `heat3d-wows-match`, `2` |
| `game`, `match`, `map`, `mapName` | `World of Warships`; id бою; карта пад назвай гульні (`spaces/<map>`) і яе паказная назва |
| `clientVersion`, `streamVersion` | версія гульні з загалоўка і яна ж, як яе называе струмень пакетаў |
| `recorded` | калі запіс быў зроблены, як яго піша гульня |
| `player`, `vehicle` | гулец, які вёў запіс, і яго карабель |
| `gameType`, `scenario` | тып бою (`RandomBattle`, ...) і сцэнарый, з загалоўка |
| `duration` | ліміт часу бою ў секундах, з загалоўка |
| `truncated` | запіс спыніўся раней |
| `battleStart`, `recordingSeconds` | пачатак бою (першы момант, калі рухаецца якісьці карабель) і працягласць запісу, у секундах |
| `positionPacket`, `ownPositionPacket` | нумары пакетаў, у якіх прыйшлі пазіцыі: чужых караблёў, гульца, які вёў запіс |
| `deathMethod` | нумар метаду, у якім знойдзены патапленні |
| `hz`, `ownHz`, `positions` | адлікаў у секунду чужых караблёў і ўласнага карабля; радкі пазіцый |
| `units` | сусветныя адзінкі (15 м па корпусах, 30 м па дальнасцях гульні); x усход, y уверх, z поўнач |
| `events` | колькасць радкоў табліцы кожнай падзеі |
| `decoded` | знойдзеныя нумары метадаў і пакетаў для кожнага віду паведамленняў |

## Гульцы і падзеі {#players-and-events}

| Ключ | Што |
|---|---|
| `players` | запіс на карабель: імя, `ally` або `enemy`, нумар і назва карабля, сутнасць, адлікі, забойствы, выжыў; `seen` (нанесены і атрыманы ўрон, снарады, тарпеды і апошняе здароўе, якое бачыў кліент); `header` (запіс са спіса ўдзельнікаў) і `record` (запіс гульца са струменя, па нумары ключа) |
| `kills` | кожнае патапленне: час, ахвяра, забойца, нумар прычыны, месца |
| `chat` | кожны радок чата, з каналам і адпраўніком |
| `damageStats` | уласная статыстыка гульца, які вёў запіс, як яе вядзе гульня: па зброі і віду, лічба і колькасць (від 0 - нанесены ўрон) |
| `avatarPickles` | кожны pickle-выклік гульцу, які вёў запіс, дэкадаваны, па нумары метаду |

## Загаловак, вынікі і праверкі {#header-results-and-checks}

| Ключ | Што |
|---|---|
| `header` | першы блок JSON, увесь, акрамя спіса ўдзельнікаў: рэжым гульні, надвор'е, мяжа карты, памеры каманд і іншае |
| `moreBlocks` | блокі JSON пасля першага, як ёсць |
| `blockIds` | 15.x: акаўнт гульца, які вёў запіс, і id бою, прачытаныя як тэкст |
| `results` | 15.x: вынікі, якія гэтыя кліенты трымаюць у струмені |
| `entities` | кожная сутнасць, якую стварае струмень: яе нумар тыпу і роля, калі яна ўвайшла ў поле зроку кліента і калі выйшла |
| `selfCheck` | лічба паўнаты ([Паўната](completeness.md)) і праверкі сутнасцей, вынікаў, id і версіі |
